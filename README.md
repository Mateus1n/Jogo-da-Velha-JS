# 🎮 Jogo da Velha — Tic-Tac-Toe

Projeto desenvolvido como atividade prática do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, durante o 2º semestre.

O objetivo do trabalho é desenvolver um jogo da velha utilizando HTML, CSS e JavaScript, colocando em prática os conhecimentos adquiridos em desenvolvimento web e lógica de programação.

## 📌 Sobre o projeto

O Jogo da Velha é um jogo para dois participantes, no qual os jogadores alternam suas jogadas utilizando os símbolos **X** e **O**.

O objetivo é formar uma sequência de três símbolos iguais na horizontal, vertical ou diagonal antes do adversário.

## 🚀 Funcionalidades

- Tabuleiro com 9 casas (3x3).
- Alternância automática entre os jogadores X e O.
- Identificação de jogadas vencedoras.
- Verificação de empate.
- Bloqueio de novas jogadas após o encerramento da partida.
- Impedimento de selecionar uma casa já preenchida.
- Botão para reiniciar a partida.
- Identificação visual dos jogadores por cores diferentes.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página e dos elementos do jogo.
- **CSS3:** estilização, cores, organização do tabuleiro e efeitos visuais.
- **JavaScript:** lógica do jogo, controle das jogadas e identificação do vencedor.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Comece a jogar!

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para executar o projeto.
